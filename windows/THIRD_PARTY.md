# 第三方组件

- .NET / WPF：Microsoft，MIT 等开源许可。[.NET](https://github.com/dotnet/runtime)、[WPF](https://github.com/dotnet/wpf)。
- Microsoft.Web.WebView2 1.0.4258.31：Microsoft WebView2 SDK 许可。[SDK](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4258.31)。运行时由 Microsoft 提供，应用调用系统已安装版本。
- SkiaSharp 4.153.1：MIT 许可；底层 Skia 及其第三方组件遵循各自许可。[SkiaSharp](https://github.com/mono/SkiaSharp)。用于安全限制尺寸的图片解码，不依赖付费图像库。
- 高德 JS SDK：通过官方在线服务加载，使用服务端配置的 Key。适用[高德服务条款](https://lbs.amap.com/home/terms/)、[隐私政策](https://lbs.amap.com/pages/privacy/)。
- 应用图标：用户提供的蓝发城市探索少女图片。
