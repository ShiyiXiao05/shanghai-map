# 魔都漫游 · Android / Windows 体验版

本次为体验版：Android 0.4.1-preview、Windows 0.1.0-preview。

## 下载与安装

- Android：下载 modu-explore-0.4.1-preview.apk，支持 Android 8 及以上。使用现有签名，可覆盖原有同签名安装包；安装由系统确认。
- Windows：下载 ModuExplore-0.1.0-preview-win-x64.exe，支持 Windows 10 2004 及以上、Windows 11 的 x64 系统。双击即可运行，已包含 .NET 运行时。
- Windows 地图需要 Microsoft Edge WebView2 Runtime。缺失时应用内提供官方下载入口。
- 两端可用相同的地图邀请码同步地点数据。首次进入公共广场；创建或加入地图后可管理个人地点、照片、留言和行程。
- SHA256SUMS.txt 提供文件校验值。Windows 的第三方许可见 Windows-THIRD-PARTY.md。

## 使用说明

Windows 版：公共广场位于主导航第一项；点击“我的地图”返回个人地图。Ctrl+F 搜索、Ctrl+N 新增、F5 刷新、Esc 收起详情。

Android 版：我的地图中可设置外观、检查更新和查看历史日志。正式版/体验版更新开关遵循应用内设置。

本次 GitHub Release 提供手动下载入口；应用内更新是否可用取决于各平台更新清单及后端部署状态。
