## 魔都漫游体验版 · Android + Windows

本次同时提供 Android 安装包和 Windows x64 便携版。两个客户端连接同一服务端，使用相同邀请码管理和同步地图。

### Android 0.4.1-preview

- 沿用旧版签名，支持覆盖安装并保留本机设置。
- 蓝发城市探索少女图标；分类默认和自定义 emoji 地点标记、144 个 emoji 预设。
- 优化首页、地点简介、详情和设置页；支持浅色、深色、跟随系统。
- 导航打开高德 App；优化想去、新增、刷新、照片及留言交互。
- 定位圆点与精度圈；体验版更新开关、历史更新日志。

### Windows 0.1.0-preview

- 首次提供 Windows 原生桌面客户端，适配桌面布局与键盘操作。
- 公共广场位于主导航，明确区分公开只读地点和个人地图。
- 支持地点编辑、想去、打卡、照片、留言、行程、回忆、海报、回收站及 JSON 导出。
- 优化暖白/墨绿界面、卡片间距、字号层级、图标和文字对齐；修复小窗口布局。
- 高德地图与列表联动，支持搜索、选点和附近地点。
