# 微信云托管迁移方案（正式发布 + 省钱版）

> 结论先行：把后端打包成 Docker 部署到**微信云托管**，可以**免域名、免备案、免 SSL 证书**直接通过小程序正式版审核。新用户前 3 个月免费，之后按我们的用量每月不到 1 块钱。
> 调研日期：2026-09-15 ｜ 官方价格：https://cloud.weixin.qq.com/cloudbase/price

## 一、为什么选云托管

正式发布微信小程序的硬门槛：`request` 合法域名必须 **HTTPS + ICP 备案**。当前后端在 Render（onrender.com，境外域名），永远无法备案。三条路的对比：

| 方案 | 首年花费 | 备案 | 上线速度 | 备注 |
|---|---|---|---|---|
| 维持体验版 | ¥0 | 不需要 | 已上线 | 90 人体验上限，每人需开一次「调试」 |
| 备案域名 + 国内服务器 | ~¥99-170 | 2-4 周 | 约 1 个月 | 域名（同学有 inwt233.cn）+ 轻量服务器 |
| **微信云托管（本方案）** | **~¥0-10** | **不需要** | **半天** | 走 `wx.cloud.callContainer` 官方通道 |

云托管本质上就是腾讯云国内容器节点，但调用走微信自家通道（`callContainer`），**不进入 request 合法域名的备案校验体系**——这是官方给个人开发者留的正道。

## 二、计费规则（按量计费）

| 计费项 | 单价 | 说明 |
|---|---|---|
| CPU 使用量 | 0.055 元/(核·小时) | 精确到 100ms |
| 内存使用量 | 0.032 元/(GB·小时) | 同上 |

| 缩容到 0 | 免费 | 最小副本数设 0 + 连续半小时无访问 → 停止计费，下次请求冷启动（等几秒） |

**新用户免费额度**：首次开通赠价值 **¥400** 资源点，有效期 **3 个月**，含 720 核·小时 CPU + 1440 GB·小时内存。720 核·小时足够 0.25 核实例 **24 小时常驻 4 个月**——即前 3 个月即使常驻也免费。

⚠️ 微信云开发体系 2026-04-23 起有免费额度政策调整，开通前建议再核对官方价格计算器。

## 四、架构变化

```
迁移前：
  小程序 ──wx.request──> Render（境外，体验版开调试才能连）
  网页   ──fetch──────> Render
  Render ──> Neon Postgres / Cloudinary CDN

迁移后：
  小程序 ──wx.cloud.callContainer──> 微信云托管（Docker 跑同一份 Express）──> Neon / Cloudinary
  网页   ──fetch──────────────────> Render（完全不动）
```

要点：
- **同一份后端代码**打 Docker 镜像，云托管和 Render 各跑一份，共用同一个 Neon 数据库——两端数据实时一致
- Neon（境外数据库）出站访问不受限，云托管容器连它没问题
- 照片继续走 Cloudinary，小程序端 `photoUrl` 需把 BASE_URL 域名部分换成云托管调用的等价物（见下）
- 网页版零改动，Render 免费额度继续用

## 五、迁移步骤

### 你要做的（约 15 分钟）

1. 打开 https://cloud.weixin.qq.com/cloudbase/price ，微信扫码开通，选**按量付费（免费试用）**环境
2. 环境需与小程序 AppID（wx45e968f2b0809dde）关联（开通流程里选这个小程序）
3. 把**环境 ID**（形如 `xxx-1a2b3c`）发给助手

### 助手来做的（半天内）

1. `server/` 加 `Dockerfile` + `container.config.json`（最小规格 0.25 核 / 0.5GB / 副本 0）
2. 云托管控制台创建服务、打通 CI（push 自动构建部署，对齐现有 Render 流）
3. 小程序端改造（唯一有代码量的部分）：
   - `utils/api.js`：请求层从 `wx.request(BASE_URL + path)` 换成 `wx.cloud.callContainer({ path, method, data, header })`，接口签名不变，页面代码零改动
   - `app.js` onLaunch 里 `wx.cloud.init({ env })`
   - 照片 URL 类接口（`photoUrl`）改走云托管路径
4. 本地 + automator 全链路回归
5. 你重新在开发者工具「上传」（或助手 CLI 上传）→ 后台设为体验版验证
6. 验证通过 → mp 后台「开发管理 → 服务器域名」无需配置任何域名 → 直接「提交审核」→ 审核通过（通常 1-7 天）→ 「发布」正式版

### 回归验证清单

- [ ] 小程序冷启动进公共广场 / 加入地图（D3JS39 → 51 地点）
- [ ] 添加地点、编辑、删除（回收站）、打卡、想去
- [ ] 照片上传与显示（经 Cloudinary）
- [ ] 行程单增删排序
- [ ] 网页版在 Render 上功能无回归（数据库共用，双端数据一致）

## 六、风险与注意

| 风险 | 说明 | 对策 |
|---|---|---|
| 冷启动延迟 | 副本缩到 0 后，停用半小时以上再打开会慢几秒 | 个人使用可接受；在意可改常驻（¥21/月） |
| 免费额度政策变动 | 2026-04-23 官方有额度政策调整 | 开通前核对价格页；用量极低，即使政策收紧成本也有限 |
| 双端部署漂移 | 云托管与 Render 各跑一份后端 | 同一镜像同一仓库，CI 统一发布 |
| 超时限制 | callContainer 有超时（默认几秒～可配） | 我们的接口都是毫秒级响应，无风险 |
| 账号欠费停机 | 按量计费需账户有余额 | 每月几毛，充 ¥10 够用一年 |

## 七、决策建议

- 现在几个人用、不着急 → **先不动，体验版够用**
- 想正式发布、入口干净（免扫码免调试）→ **执行本方案**，半天上线，首年成本趋近于零
- 未来如果用户量大或需要自有域名网页 → 再评估备案 + 独立服务器，云托管随时可退（Docker 镜像本来就是标准格式）
