# Android 0.4.0 体验版

发布日期：2026-10-09。包名 `com.modu.explore`，版本名 `0.4.0-preview`，版本码 `4`。

## 更新内容

- 更换为用户最新提供的蓝发城市探索少女应用图标，适配圆形和圆角桌面裁切。
- 地图标记使用分类默认 emoji，地点编辑支持选择、自定义及恢复默认；服务端持久保存。
- 地点和行程导航直接打开高德 App 的步行路线规划。
- 首页本机缓存，刷新保留已有内容；点赞、新增地点和留言即时显示，失败回退并保留编辑内容。
- 详情预取与短时缓存，照片和留言独立显示；上传后直接展示缩略图，地图标记增量更新。
- 改善配色与控件样式；新增正式版/体验版更新渠道、体验版开关和历史更新日志。

## 发布方式

体验版进入 `public/android/releases.json`，不覆盖供旧客户端使用的正式版 `update.json`。已经安装旧版的用户首次需从体验版下载链接手动安装；体验版客户端可在「检查更新」开启体验版更新。关闭该选项时仅提示正式版。

后续正式版版本码必须高于已发布体验版，签名需保持一致，系统安装需要用户确认。

## 验证

Android 25 项单元测试全部通过，release lint 无错误，签名 release 构建成功。后端本机 112 项测试通过；另有一项现存测试使用 Linux 绝对路径导入方式，在 Windows 环境不兼容，完整测试由 Ubuntu CI 执行。后端字段回归覆盖 emoji 保存、修改、恢复默认、公共读取与导出。高德 App 跳转及桌面图标裁切仍需真机验证。
