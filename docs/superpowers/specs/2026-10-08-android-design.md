# Android 原生客户端

用户已确认沿用当前小程序布局和配色，独立实现 Android UI；先生成 APK，之后补高德 Android Key。

- 独立 `android/` 工程，Kotlin、Jetpack Compose、Material 3，最低 Android 8。
- 首页沿用顶部地图切换及动作、地图、工具栏、分类筛选、地点列表；深浅配色取自小程序。
- 复用 Express HTTPS API 与 GCJ-02 坐标。邀请码授权、昵称署名沿用网页机制，不模拟微信登录。
- 创建/加入/切换地图、公共广场、地点增改删、打卡、想去、公开、照片、留言、举报、行程、回忆、海报、回收站及地图管理使用原生页面。
- 高德原生地图及搜索使用 Android SDK Key。Key 通过本地配置或 CI 注入；未配置时明确提示，保留列表与已有地点操作，不呈现虚假地图。
- 相册选择使用系统选择器，上传前按服务端预算压缩；导出、海报保存使用系统文档选择器；导航通过 Android Intent。
- 用户主动开启地图后才初始化地图 SDK，并先取得隐私同意；拒绝不影响列表功能。定位权限按需请求。
- 网络异常显示可重试状态；写操作禁止并发点击且不自动重放。页面离开/地图切换避免旧响应覆盖新地图。
- 输出调试签名 APK 供侧载体验，提供正式签名构建说明。缺 Key 时不声称地图已验证；未运行真机时明确记录验证范围。

验证：API 解析与错误契约测试、筛选排序及行程测试、原生构建与 lint、已有服务端回归测试；条件允许时运行模拟器并检查实际截图。
