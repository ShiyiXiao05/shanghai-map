# Android Implementation Plan

**Goal:** 生成沿用小程序布局和配色、复用现有数据的原生 Android APK。

**Architecture:** Android 独立工程，Compose 页面、ViewModel 状态、API 数据层分离。地图以原生高德 MapView 集成，未配置 Key 时保留非地图流程。

**Tech Stack:** Kotlin, Jetpack Compose, Material 3, OkHttp, kotlinx.serialization, Coil, AMap Android SDK, JUnit。

**Spec:** `docs/superpowers/specs/2026-10-08-android-design.md`

## Constraints

- Android 8 起；与现有网页/小程序共用数据；不更改已有客户端和服务端行为。
- 首版无需高德 Key 即可构建，但真实地图/搜索须补 Key。
- 本次在当前会话按以下任务顺序执行，不提交用户原有未提交修改。
