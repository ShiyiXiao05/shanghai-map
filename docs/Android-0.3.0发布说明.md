# Android 0.3.0 发布说明

日期：2026-10-08。包名 `com.modu.explore`，`versionCode=3`，保留 0.2.0 的签名，可覆盖安装并保留本地设置。

## 更新内容

- 接入用户提供的沪娘图标，使用 Android 自适应图标兼容不同桌面裁切。
- 首页地图/地点栏增加可拖动分隔条，调整比例为 25%–70%，支持页面状态恢复和无障碍调整。
- 标记改为简洁定位针，保留高对比度、深橙色美食和已去过角标。
- 抽地点增加约 2.4 秒滚轮减速动画，停止后查看结果或再次抽取。
- 点赞、公开切换、打卡、保存地点和留言增删等操作使用服务端响应更新本地状态，减少无关读取。
- 首页和详情独立请求并行，避免点赞/计数变化导致标记重绘。
- 修复打卡日期同步、详情重试与写入的竞态，以及旧首页加载覆盖写入结果的问题。

## 发布文件

- `public/android/modu-explore-0.3.0.apk`
- `public/android/update.json`，更新地址保持不变。
- 本地直接安装文件：`android/dist/modu-explore-0.3.0-debug.apk`。

安装包为调试签名体验版。实际文件 SHA-256 以更新清单为准，必须与线上下载文件一致。不要用其他电脑/CI 的默认调试签名替换它。

## 部署与验收

推送发布提交到 Render 关联的 `main`。若未自动部署，在现有服务选择 Manual Deploy → Deploy latest commit。服务的 Root Directory 应留空，Build 为 `npm --prefix server ci`，Start 为 `npm --prefix server start`。保留现有数据库及所有环境变量。

确认线上 `/android/update.json` 的 `versionCode=3`、下载地址为 `/android/modu-explore-0.3.0.apk`；完整下载 APK 并校验清单 SHA-256。在已安装 0.2.0 的手机中点击「我的地图 → 检查更新」，下载后由系统确认安装；首次需要允许应用安装更新。验证昵称、邀请码、地图内容、照片与留言仍可访问。

更完整的部署和故障排查步骤见 [Render 更新交接](Render-Android更新部署交接.md)。线上列表请求的服务端延迟仍可能存在，排查依据见 [性能记录](Android性能与更新验证-2026-10-08.md)。

## 验证范围

发布前执行 JVM 测试、Android 15 模拟器回归、lint 与 APK 构建。拖动分隔条和滚轮界面已经过模拟器截图检查。实际地图效果、不同手机的桌面图标裁切和系统安装提示仍应在真机验收。
